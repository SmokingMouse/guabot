# Quickstart: Agent 脚手架

本指南说明如何在本地以最小配置运行 Agent 脚手架，实现：

- 在单一 IM 渠道（例如内部模拟或简单 HTTP 客户端）上实现一问一答；
- 通过统一能力层调用一个示例“时间查询”工具；
- 验证会话记忆窗口 N 的基本行为。

## 前置条件

- 安装 Python 3.12；
- 安装项目依赖（后续在实现阶段补充具体命令）；
- 拥有一个可用于测试的 IM 渠道或本地模拟端点。

## 步骤概览

1. 启动脚手架服务（本地或容器内运行）。
2. 在 IM 渠道中配置回调地址指向脚手架的 `/im/webhook/{channel}` 接口。
3. 在配置文件中启用示例能力（如“当前时间”）。
4. 在 IM 中向助手发送测试消息，观察回复与日志。

## 验证点

- 能够在 IM 中完成一次完整的消息往返；
- 在启用/关闭示例能力时，回复内容有可观区别；
- 多轮对话中，Agent 能正确引用最近 N 条上下文。
